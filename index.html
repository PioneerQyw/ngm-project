01 / THE IDEA

A new role for
existing embeddings.

Can a pretrained embedding space serve as local memory without retraining or a separate memory table?

NGM builds causal, multi-scale N-gram representations directly from the backbone’s token embeddings. A cosine gate then selects positively aligned signals and writes them into the decoder’s residual stream.

The result is a two-stage memory mechanism that leaves the model’s weights frozen and introduces no learned memory representations.

02 / HOW IT WORKS

Construct. Gate. Inject.

Two parameter-free components.
One pretrained representation space.

01

Causal N-gram encoder

Average pretrained embeddings over trailing windows. The default 2-gram and 3-gram windows expose local patterns at different scales.

gt,n = 1/n ∑k=0n−1 E[xt−k]
02

Cosine-gated injector

Measure compatibility with the decoder state. ReLU suppresses negative alignment; a fixed scale controls the residual write.

h′t = ht + λ ∑n ReLU(cos(ht, gt,n)) gt,n
WHY THIS CAN WORK

Local structure remains
in the embedding space.

In Qwen3-8B, actual N-gram representations align more strongly with decoder hidden states than position-shuffled and random-token controls. This motivates a geometric gate without a learned projection.
